Verbindung zu GitHub

Noch nicht verbunden

So bekommst du den Schlüssel (einmalig, ca. 2 Minuten)
  1. Auf github.com anmelden, oben rechts aufs Profilbild → Settings.
  2. Ganz unten links Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Name z. B. „Galerie-Upload“, Ablauf z. B. 1 Jahr.
  4. Bei Repository access: „Only select repositories“ → website auswählen.
  5. Bei Permissions → Contents auf Read and write stellen.
  6. Generate token, den Schlüssel kopieren und hier einfügen.
Der Schlüssel wird nur in diesem Browser auf diesem Gerät gespeichert. Gib ihn niemandem weiter.
