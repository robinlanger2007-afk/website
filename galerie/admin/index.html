Einrichtung (einmalig, ca. 15 Minuten – am besten am Computer)
  1. Auf dash.cloudflare.com kostenlos registrieren und die E-Mail bestätigen.
  2. Links R2 Object Storage öffnen und aktivieren. Cloudflare möchte dafür eine Zahlungsmethode – bis 10 GB kostet es aber nichts.
  3. Create bucket → Name galerie → bei Location „Provide a location hint“ Western Europe wählen → Create bucket.
  4. Links Compute (Workers) → Workers & Pages → Create → Start with Hello World → Name galerie → Deploy.
  5. Edit code → den vorhandenen Code komplett löschen → diesen hier einfügen → oben rechts Deploy.
  6. Zurück zum Worker → Bindings → Add binding → R2 bucket → Variable name BUCKET, Bucket galerie → Add binding.
  7. Settings → Variables and Secrets → Add → Type Secret, Name ADMIN_KEY, Value: den Admin-Schlüssel unten (erst Erzeugen, dann Kopieren) → Deploy.
  8. Die Worker-Adresse (endet auf .workers.dev, steht oben auf der Worker-Seite) unten einfügen und auf Speichern & verbinden tippen.
